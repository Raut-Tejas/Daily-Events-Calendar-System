# Cloud-Based Daily Events & Indian Calendar Notification System

## About the Project

This project is a web application that helps people stay updated about daily events, Indian festivals, national holidays, and important dates.

The main idea behind this project is to make it easier for users to remember important occasions and receive notifications about upcoming events.
Users will be able to view daily events, explore the Indian calendar, and add personal events like birthdays and anniversaries.

I am developing this project to gain practical knowledge of web development, cloud computing, and database management.

## Features

- View daily events and important dates.
- Explore Indian festivals and national holidays.
- Check upcoming events through a calendar.
- Add personal events like birthdays and anniversaries.
- Receive reminders about upcoming events.
- Search events by date, name, or category.
- Access the application online through cloud hosting.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- PostgreSQL
- Git and GitHub
- AWS Cloud

## How the Project Works

Users will be able to open the website and check daily events, festivals, and upcoming holidays.

The application will store event information in a PostgreSQL database. 
Flask will handle the applicationlogic and connect the website with the database.

The notification system will help users remember important dates and upcoming events.

After completing the application, I plan to deploy it on AWS so users can access it through the internet.
